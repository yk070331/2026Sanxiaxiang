# 红韵乔林 - 井冈山红色文旅小程序

## 项目简介

"红韵乔林"是一款依托高清井冈山市全域矢量电子地图的微信小程序，以茅坪镇乔林村为核心，展示井冈山红色文化、革命旧址、古村风貌和研学路线。

## 功能架构

### 1. 首页 · 全域地图
- 全屏高清矢量地图，展示井冈山市全域
- 两类可视化点位：
  - ★ **红色五角星**：标注黄洋界、八角楼等7处市级核心红色地标
  - 🏘️ **古村图标**：标记乔林村及周边3个红色村落
- 支持缩放、滑动自由浏览
- 点击图标弹出信息卡片，快速查看详情

### 2. 村落详情页
- 村落概况 Hero 区域（人口、面积、党员数）
- 四大入口卡片：村情信息、红色故事、实景相册、研学导览
- 6处村内红色旧址列表（可逐一进入详情、一键导航）
- 研学路线快捷横幅

### 3. 旧址详情页
- 历史沿革详细介绍
- 关联红色故事推荐
- 实景影像入口
- 一键导航功能

### 4. 红色故事板块
- 6篇实地采集的革命故事（革命往事 + 红色人物）
- 分类筛选
- 音频播放器：支持村民口述原声音频播放（进度条、播放/暂停）
- 来源信息标注（口述人、采集日期、关联地点）

### 5. 实景相册板块
- 14张实拍影像（占位）
- 三大分类：革命旧址、古村落、水源山林
- 网格布局 + 大图预览轮播
- 支持微信原生图片预览

### 6. 研学导览板块
- 2.3公里红色研学路线
- 8个站点（起点、6处红色旧址、终点）
- 站点轮播 + 详细描述 + 小贴士
- 打卡功能（振动反馈 + 进度条）
- 站点快速跳转导航
- 一键导航到任意站点

### 7. 村情信息板块
- 7大分类台账：基本村情、土地资源、水利水源、基础设施、公共服务、集体经济、红色资源
- 标准化键值对展示

## 演示流程

1. 打开小程序 → 加载井冈山全域地图
2. 右下角点击"乔林村"按钮 → 自动定位到茅坪镇乔林村
3. 点击乔林村图标 → 弹出信息卡片（人口、面积、6处旧址快捷入口、研学路线导航）
4. 点击"进入详情" → 村落详情页（四入口卡片）
5. 点击"红色故事" → 故事列表 → 选择故事 → 文字阅读 + 音频播放
6. 点击"研学导览" → 路线站点 → 依次打卡 → 一键导航

## 素材替换说明

实际部署前，需要替换以下占位素材：

1. **标记图标** (`miniprogram/images/icons/`): 已生成基础PNG，可替换为设计师制作的图标
2. **实景照片** (`miniprogram/assets/images/`): 上传驻村实地拍摄的影像
3. **口述音频** (`miniprogram/assets/audio/`): 上传村民口述原声录音（MP3格式）
4. **分享封面** (`miniprogram/assets/images/share_cover.jpg`): 替换为实际封面图

## 技术栈

- 微信小程序原生框架（WXML + WXSS + JS）
- 微信地图组件（`<map>`）
- 微信云开发（`wx.cloud`）
- 微信音频 API（`InnerAudioContext`）
- 微信导航 API（`wx.openLocation`）
