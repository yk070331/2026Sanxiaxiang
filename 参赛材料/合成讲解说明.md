# 普通话合成讲解

2026-09-20 制作六段通用普通话导览，使用本机 Windows System.Speech 的 Microsoft Huihui Desktop 语音，语速 -1。音频为系统语音合成，不克隆任何具体人物，不属于村民、讲解员或革命人物原声。

## 内容与来源

讲解稿及公开资料链接保存在 `miniprogram/utils/narrationScripts.js`，可在故事详情的“本段讲解稿”中阅读并复制来源链接。每段开头明确播报合成身份；列表、播放区域也有文字标识。口述署名与采录日期属于原有文字资料，不能作为合成声音的来源。

八角楼、黄洋界、朱德扁担三段是公开资料基础上的简短导览；另三段以村级史料待核验说明与观察提示为主，不播报尚无依据的精确人数、人物经历或修建年份。合成讲解不是原故事逐字朗读，完整原有文字与审核状态仍在页面中保留。

## 文件与验证

- 六个文件位于 `miniprogram/audio/story_1.mp3` 至 `story_6.mp3`。
- 单段约42–46秒，单声道、22050 Hz、24 kbps；真实播放时长由播放器读取。
- 制作引擎、时长、大小和 SHA-256 见《合成讲解制作记录.json》。已用 FFmpeg 解码全部文件，检查非静音及文件完整性。
- 音频只使用本地文件，无需向第三方服务上传游客数据。未附加背景音乐。
- 这批语音不能替代后续真人采访、口述授权和史料审核。

## 重新生成（Windows）

已安装相应中文系统语音及 FFmpeg 时执行：

```powershell
.\scripts\generate_narration.ps1 -FfmpegPath '你的ffmpeg.exe路径' -WaveDirectory '本机临时WAV目录'
```

修改稿件或重新生成后，需要重新检查时长、声音和文件哈希，并更新制作记录；`tests/mediaLibrary.test.js` 会检查音频与记录是否一致。
