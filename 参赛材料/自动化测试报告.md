## 4. 执行方式与结果

逐项执行：

```powershell
Get-ChildItem tests -Filter *.test.js | Sort-Object Name | ForEach-Object { node $_.FullName }
node scripts/release-readiness.js
```

最近一次结果：12个测试脚本全部通过；`staticPages.test.js` 检查127个文件；发布检查为 `21 PASS / 4 WARN / 0 FAIL`。

四项提醒均属于真实上线输入，不是自动化失败：默认云环境ID、12条相册占位素材、3—5分钟演示成片、开发者工具与真机验收。
