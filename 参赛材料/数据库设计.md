# 红韵乔林数据库设计

## 1. 设计目标

数据库用于支持村落、地图点位、红色故事、文物史实、研学路线、游客打卡、资料纠错和后台审核。第一阶段采用微信云开发数据库；网络不可用时，小程序读取本地已审核数据作为降级方案。

## 3. 权限原则

- 游客只能读取 `published` 内容。
- 游客只能新增自己的打卡和纠错记录，不能修改正式史料。
- 村级录入员可提交草稿，不能直接发布。
- 团队管理员可整理资料并提交审核。
- 审核员确认后才能将内容设为 `published`。
- 所有修改保留操作者、时间和审核记录。

## 4. 主要关系

- 一个村落包含多个点位。
- 一个点位可以关联多个故事和素材。
- 一条路线按顺序包含多个点位。
- 一个用户可以对多个点位打卡，也可以提交多条纠错记录。
