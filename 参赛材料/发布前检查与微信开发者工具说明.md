## 二、一条命令执行发布体检

在项目根目录运行：

```powershell
node scripts/release-readiness.js
```

体检覆盖项目配置、页面四件套、定位隐私声明、核心云函数、云环境配置、腾讯地图坐标、本地素材引用、主包静态体积、Git 强特征密钥、私人文件、参赛 PDF 和演示视频。

- `FAIL`：必须先修复，不应上传。
- `WARN`：允许代码继续运行，但必须在最终参赛提交前处理或人工复核。
- `PASS`：仓库层面的自动检查已通过；不替代开发者工具和真机验证。

## 三、配置云开发环境

推荐正式发布前，将云开发环境 ID 填入 `miniprogram/config/env.js` 的 `DEFAULT_ENV_ID`。如暂时不希望把环境 ID 写进仓库，可在微信开发者工具调试器 Console 中执行：

```javascript
wx.setStorageSync('qiaolinCloudEnvId', '你的云环境ID')
```

然后重新编译。清除本机配置可执行：

```javascript
wx.removeStorageSync('qiaolinCloudEnvId')
```

环境 ID 不是管理员密码，但正式仓库仍不得提交 `project.private.config.json`、私钥、访问令牌或云数据库管理员凭据。

## 四、部署云函数

在微信开发者工具中依次右键以下目录，选择“上传并部署：云端安装依赖”：

1. `cloudfunctions/contentService`
2. `cloudfunctions/visitorRecords`
3. `cloudfunctions/contentAdmin`

随后按照《云开发部署说明》和《数据库设计》创建集合、索引与权限，并使用管理员 OPENID 配置角色。游客端只应读取已发布内容；审核、发布等操作必须由云函数校验权限。

## 五、打开开发者工具 CLI 服务端口

当前机器的开发者工具图形界面可以启动，但 CLI 检查发现“服务端口”仍未真正保持开启，因此尚不能把 CLI 编译写成已通过证据。请在 Microsoft Edge 之外的微信开发者工具本身完成以下设置：

1. 打开微信开发者工具。
2. 进入“设置”→“安全设置”。
3. 开启“服务端口”。
4. 保持开发者工具打开，再执行本节命令。

示例命令（端口以工具界面实际显示为准）：

```powershell
& 'D:\微信web开发者工具\cli.bat' open --project 'D:\2026Sanxiaxiang\2026Sanxiaxiang'
& 'D:\微信web开发者工具\cli.bat' preview --project 'D:\2026Sanxiaxiang\2026Sanxiaxiang'
```

若 CLI 继续提示服务端口关闭，应回到工具界面确认开关，不要修改或提交微信开发者工具个人配置文件。

## 六、必须完成的人工验收

1. 编译无错误、无阻断性警告，检查主包和分包分析结果。
2. 首页首次定位授权、拒绝授权、再次授权三种流程均可理解且不会卡死。
3. 乔林村与乔林水库分别点击“打开地图”，名称和落点与腾讯地图分享位置一致。
4. 完成一条 60 分钟路线，验证下一站提示、知识题、打卡、纪念章和证书闭环。
5. 开启飞行模式或断网，验证本地图片、文字、缓存记录与恢复网络后的补传。
6. 在至少一台 Android 和一台 iPhone 真机验证地图、扫码、字体、按钮、滚动和图片预览。
7. 使用游客、村级录入员、团队管理员三类账号验证读写与审核权限边界。
8. 提交一条纠错，确认离线队列、云端记录和后台处理状态一致。
